# User Stories

## Alex — Group Chat Starter

### Story 1
As Alex, I want to generate an AI-swapped meme in under 5 minutes so that the joke remains relevant to the current conversation.

### Story 2
As Alex, I want to access a fully responsive web interface so that I can create memes on the go without a desktop computer.

### Story 3
As Alex, I want the AI to preserve the original meme's text and style so that the resulting image is instantly recognizable as a specific meme.


## Marcus — OG Meme Enthusiast

### Story 4
As Marcus, I want to upload a custom photo to a classic meme template so that I can make my friends part of the meme lore.

### Story 5
As Marcus, I want to see evidence of prompt-caching or token accounting in the app's workflow so that I can regenerate the same meme from my history.


## Taylor — Social Connector

### Story 6
As Taylor, I want the tool to only suggest PG-13 content so that I can safely demo the app to my Professor and TA.

### Story 7
As Taylor, I want a direct "share" button for my generated meme so that I don't have to manually save it to my Photos app first.

### Story 8
As Taylor, I want to access a fully responsive web interface so that I can create and share memes easily from my phone.
